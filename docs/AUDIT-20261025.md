The native fixture used separate user data, credentials, port and directories.
Post-shutdown verification checked ownership, hardlinks, restored sentinel bytes
and filesystem identity, four durable completions, absence of an unresolved
operation and clean process exit. No game was launched. Real Nexus download reuse
was not tested in this fixture: the local test archive had no legitimate Nexus
file identity, and none was fabricated.

The ordinary loaded adapter exposes 15 tools. This candidate exposes 16, adding
the bounded `read_collection_health` projection. Native installation remains
unavailable through the public adapter; the isolated fixture's explicit native
setup is not a general installation API.

The optional upstream `docs:tools:check` expects an unauthenticated upstream
server and received HTTP 401 from the guarded endpoint. Authentication was kept
enabled; this optional generator is not reported as passing.

The upstream GitHub API was also checked for the other two tools. The community
CLI's latest published release remains `v1.1.1`; the official uploader's current
HEAD remains `98532f7670c27cbecc78fae03fa3e278147827e2`. Both match the retained
pins, so neither was changed merely to produce an upgrade.

A live read-only session inspected mods, downloads, dialogs and external changes
in about two seconds without restarting Vortex or manipulating its window. This
is one observation, not a universal latency or game-performance benchmark.

Recovery was exercised from a fresh private GitHub clone: all 21 skill files
restored and a client template was prepared in a different path containing spaces.
All three source bundles restored their pinned commits. A shallow uploader bundle
failed that exercise and was replaced with a complete-history bundle before
publication. Existing live client configuration and credentials were untouched.

Raw runtime receipts remain local because they contain machine-specific paths.
Source pins, dependency changes, recovery assets and their hashes are public.
Tests establish the checked boundaries; they do not prove arbitrary mod or game
compatibility, prevent native Vortex dialogs, or make repeated writes safe without
request-ID reconciliation.
