# Support

Start with [Get started](docs/GETTING-STARTED.md) and its troubleshooting table.
For a reproducible problem, open a
[bug report](https://github.com/Antrakt92/Nexus-Modding-Tools/issues/new?template=bug-report.yml).
For a capability you need, open a
[feature request](https://github.com/Antrakt92/Nexus-Modding-Tools/issues/new?template=feature-request.yml).

Include the source release or commit, tool name, relevant Windows/Vortex/Node/Python
versions, a minimal command and the observed result. Separate terminal/static
checks, native Vortex behavior and gameplay observations. If a write has an
uncertain outcome, preserve its receipts and stop before retrying.

Review every attachment. Remove tokens, keys, signed URLs, account information
and private paths. Do not attach a Vortex database, credential store, full state
dump, game archive or mod archive. Share the smallest sanitized excerpt that
demonstrates the problem. For vulnerabilities, use [private reporting](.github/SECURITY.md).

This project covers its maintained bridge, adapter, wrappers and preparation
helpers. Problems in a third-party mod or Vortex itself may need the respective
upstream maintainer. Reports are welcome; no response-time SLA is promised.
